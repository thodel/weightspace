## Plan

Act on the data defect of [phase 0](2026-11-06-a-phase0.md): restore the
correctly paired Hertwig pages in the published dataset, build a Bern held-out
set (6 Hertwig and 8 Schlussredaktion test pages, 545 lines, audited at page
level), and run the first session on target 1, `bern-combined-v1`: *can a
weight-space edit undo training on label noise?* Donors: the parent
`hertwig-v2` and the clean sibling `schlussredaktion-v1`.

## Done

- The dataset was repaired by hand the same evening: the two re-exported
  Hertwig shards were replaced by the byte-identical earlier files and
  verified.
- The third model family (from-scratch runs whose training material was not
  archived) was dropped as a target; the lossless rewrite (R1) stays.
- Session: 8 edits — blank bias to the parent, output layer, each LSTM and the
  conv stack from the sibling, the output layer from the parent, the last LSTM
  half-way to the parent. Under the [A1](../amendments.md#a1) keep rule, one
  edit was kept: **the output layer from the parent** (practice −0.42 points,
  interval [−0.85, −0.04]).

## Found

**The premise did not hold.** The figure that made `combined-v1` look broken
(28.8 % against 16.7 %) came from mismatched pages and different sets. On
correctly paired held-out pages it is the best model of the family:

| held-out CER (545 lines) | all | Hertwig | Schlussredaktion |
|---|---:|---:|---:|
| `combined-v1` | **19.3 %** | 26.7 % | 13.5 % |
| `hertwig-v2` (parent) | 27.5 % | 23.6 % | 30.6 % |
| `schlussredaktion-v1` (sibling) | 20.4 % | 29.5 % | 13.1 % |

The label noise cost it about three points on the Hertwig hand.

**The kept edit is not a gain:** held-out +0.15 points [−0.10, +0.42]; it
trades a non-significant Hertwig gain for a significant Schlussredaktion loss
(+0.51 [+0.21, +0.82]). Its practice gain came from the 103 Hertwig practice
lines, which are the *donor's own training lines*: the parent's output layer
fits them, so the transplant looks good on practice and does not transfer.

## Changes

- This is the origin of the proposed donor rule and of the move to practice
  lines the subject was not trained on ([A3](../amendments.md#a3)).
- The honest comparator for target 1 is a retrain on the corrected data (C4);
  it needs a go-ahead and has not been run.
