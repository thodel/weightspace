# 2026-11-06 · Phase 4: the collapsed lines are a data question

**Phase:** 4 · **Budget spent:** none · **Held-out touched:** re-aggregation only ·
**Source:** `docs/PHASE4_REPORT.md`, `docs/collapse/`

## Plan

[Phase 1](2026-11-06-b-phase1.md) left 428 held-out lines on which
`german-xix-blb-v1` "collapses". Find what they share; separate *the crop is
bad* from *the model fails on a readable line*; propose a weight-space session
only if a readable subset exists.

## Done

Each flagged line was put in one class, using the parent as the sibling that
decides "model-specific"; contact sheets of every class were inspected by eye.

| class | lines | share of all held-out edits |
|---|---:|---:|
| degenerate box (1–7 px high, reference a whole line) | 111 | 25.9 % |
| vertical line (envelopes, margins) | 100 | 8.5 % |
| detector false positive (correct text) | 142 | 2.3 % |
| short for every model (OCR junk as reference, upside-down lines, …) | 36 | 1.3 % |
| box holds more than its text | 9 | 1.4 % |
| reference of 1–3 characters | 30 | 0.5 % |
| **model-specific (the parent reads it)** | **0** | 0 |

## Found

- **None of the 428 lines is a readable handwritten line the model gets
  wrong.** Together they carry 40 % of the held-out errors.
- **Half of the handwriting test set was a printed book.** One shelfmark, filed
  under manuscripts, is a printed edition of 1853 whose references are the
  library's own OCR of the print; its 2,825 lines are half of the held-out set,
  and all 111 degenerate boxes are in it.
- The collapse detector flagged correct long lines: any character trigram six
  times (` . `, `en `) counted as a loop.
- Re-cut crops (degenerate boxes widened, vertical lines rotated) bring the
  held-out CER from 12.3 % to 9.6 %; leaving the defects out gives 8.1 %. The
  gap between phase 1's 12.3 % and the trainer's recorded 8.7 % is these lines.

## Changes

- **No weight-space session is proposed** for the collapsed lines.
- The detector and the held-out set are fixed in [phase 5](2026-11-07-a-phase5.md).
- The box, orientation and OCR-reference defects are reported to the dataset
  owners.
