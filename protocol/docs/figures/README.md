# Figures

Generated by `wsp.viz` — do not edit by hand. Regenerate with

```bash
python -m wsp.viz all --out protocol/docs/figures
```

Each figure exists twice: `<name>.svg` (light) and `<name>-dark.svg` (dark). In MkDocs Material:

```markdown
![caption](figures/<name>.svg#only-light)
![caption](figures/<name>-dark.svg#only-dark)
```

Colours are Okabe–Ito (colour-blind safe). No forward pass and no held-out data went into any figure.
