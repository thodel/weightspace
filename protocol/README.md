# protocol/ — the publishable research protocol

A MkDocs (Material) site: the public, dated record of this project. The
internal working documents stay in `docs/` and `runs/`; this folder holds
what an outside reader needs, written for them. Not published yet — see
[PUBLISHING.md](PUBLISHING.md).

```
docs/index.md          overview and current status
docs/method.md         the rules in force (public form of docs/PROTOCOL.md)
docs/amendments.md     every rule change, dated, with reason and sessions affected
docs/journal/          one entry per event, YYYY-MM-DD-<letter>-<slug>.md
docs/results.md        the paper-grade numbers (public form of docs/RESULTS.md)
docs/figures/          figures, regenerated by `python -m wsp.viz`; zoo/ and family/
                       are copies of docs/zoo/figures and docs/family/figures,
                       probes/ of docs/viz — re-copy after regenerating
docs/_templates/       entry template (not built)
```

## Adding an entry

1. Copy `docs/_templates/entry.md` to `docs/journal/<date>-<letter>-<slug>.md`
   (letters order entries of one day).
2. Add it to `nav` in `mkdocs.yml` and to the table in `docs/journal/index.md`.
3. A rule change also gets an `amendments.md` section and a `method.md` edit;
   a held-out number also goes into `results.md`; update the status box in
   `index.md`.
4. Entries are append-only: a correction is a new entry naming the old one.

## Build locally

```bash
python -m venv /tmp/mkdocs-venv && /tmp/mkdocs-venv/bin/pip install -r protocol/requirements.txt
/tmp/mkdocs-venv/bin/mkdocs serve -f protocol/mkdocs.yml      # http://127.0.0.1:8000
/tmp/mkdocs-venv/bin/mkdocs build -f protocol/mkdocs.yml      # strict; output in protocol/site/
```
